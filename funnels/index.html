Questions

The ones everybody asks.

How long does setup take?

One 15-minute call to learn how you work, then we install. Most businesses are live within a week — the missed-call text-back is usually running the same day.

Do I need to be technical?

No. You get a login and a phone app. Everything else is built and maintained by us.

Does it replace my phone number?

No. Your number stays. We add a business line the system uses for texts and, on Premium, for the AI voice agent — and it can forward to you.

What if I already have a CRM?

We'll either connect to it or move you — most owners find the one we install is the first one they actually use.

Can I cancel?

Yes. Month to month after setup, 30 days' notice. Your contacts are yours and export any time.

Is this the same thing as Signature Agent OS?

Same engine, different job. Funnels is tools installed that you run. Agent OS is a complete system for insurance agencies — installed and run for you, with AI that writes and outbound that brings the leads. If you sell insurance, start there.
